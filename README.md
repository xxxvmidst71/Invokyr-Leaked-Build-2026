## 🕹️ About

Invokyr is a first-person co-op survival horror game from Ludogram, built around a cursed 1970s board game inside an abandoned house. Roll the dice, explore the manor, survive summoned creatures, traps, and curses, and defeat the Gamemaster to escape. This repository contains an unofficial leaked Windows pre-release build that surfaced before the finished release.

For players who want tense first-person horror, chaotic co-op sessions, supernatural mysteries, and an unpolished build that feels like it escaped the lab.

> ⚠️ **This is an unofficial leaked pre-release build.** The game is under active development: expect bugs, unfinished content, and balance changes.Archive is password protected (`2026`) to compatibility automated DMCA bots and hosting service scanners that would otherwise delete the files within hours.

## ✨ Features

- 🎲 **Cursed Board Game** — Roll the dice and trigger unpredictable horrors throughout the house.
- 👥 **Online Co-op** — Play alone or survive with up to three friends.
- 🏚️ **Abandoned Manor** — Explore a labyrinth of rooms while trying not to lose your way.
- 🔍 **Hidden Dice** — Search the house for dice, each usable only once.
- ✨ **Special Powers** — Use special dice to heal, hide, or hinder the things hunting you.
- 👹 **Summoned Horrors** — Face bizarre creatures with unique ways of hunting.
- 🌀 **Changing Biomes** — Survive strange environments including jungle, ice mountain, and an oversized toy chest.
- 🏆 **Earned Challenges** — Survive runs, earn rewards, and unlock more formidable challenges.
